# Atividade de Fixação 07 - Dashboard

Projeto de dashboard feito em Python com Streamlit, Pandas, Matplotlib e Seaborn,
adaptado a partir do arquivo `app.py` fornecido.

## Estrutura esperada

Coloque na mesma pasta do `app.py` os arquivos CSV abaixo:

- `dados_linhas.csv`
- `dados_barras.csv`
- `dados_pizza.csv`
- `dados_distribuicao.csv`
- `dados_boxplot.csv`
- `dados_frequencia.csv`
- `dados_dispersao.csv`
- `dados_regressao.csv`
- `dados_heatmap.csv`

## Como executar

1. Instale Python 3.10 ou superior.
2. Abra o terminal nesta pasta.
3. Instale as dependências:

   ```bash
   pip install -r requirements.txt
   ```

4. Execute o dashboard:

   ```bash
   streamlit run app.py
   ```

## Publicar no GitHub

1. Crie um repositório chamado `Atividade de Fixação 07 - Dashboard`.
2. Envie `app.py`, `README.md`, `requirements.txt` e os arquivos CSV necessários.
3. Não inclua arquivos com dados pessoais ou secretos.

## Observação

O dashboard depende dos arquivos CSV listados. Eles não estavam incluídos no arquivo
recebido; adicione-os antes de executar o projeto.
